# CA3P Agent Loop — 로컬 대시보드

`DESIGN.md`의 검정 배경, 민트·제이드 별빛과 주변광을 적용한 에이전트 텔레메트리 대시보드입니다. 참조 문서의 장면 복제 지시와 구분하여 대시보드 UI를 새로 구성했습니다.

## 실행

Node.js만 필요하며 패키지를 설치할 필요가 없습니다.

```powershell
cd agent-dashboard
npm run dev
```

브라우저에서 <http://127.0.0.1:4173>을 엽니다. 서버는 `127.0.0.1`에만 바인딩합니다. 터미널에서 `Ctrl+C`로 종료합니다. 다른 포트를 사용하려면 `$env:PORT = '4174'`를 설정한 뒤 실행하세요.

## 구현 기능

- URL 입력과 검증 → 6개 모듈, 3회 반복, 18단계 **모의 루프**
- 실시간 루프 그래프, 현재 단계, 반복 횟수, 실행 시간, 진행률
- 모듈별 요청·응답 JSON과 Correlation ID, 예시 지연 시간
- 에이전트 입력과 출력 요약 (Agent I/O)
- 일시정지·재개·중지, 최신 이벤트 자동 표시, 이벤트 검색
- 브라우저에 최근 12개 실행 저장, 이력 열람, 현재 실행으로 복귀
- 검토 항목과 예시 근거 리포트, JSON 복사·내보내기
- 모바일 반응형 화면, 키보드 탭 조작, Ctrl/Cmd+K URL 입력, reduced-motion 지원
- 배경 애니메이션·이벤트 속도 설정

## 실행 범위

이 버전은 **로컬 시뮬레이터**입니다. 입력한 URL에 접속하지 않고, 외부 에이전트·게이트웨이·펜테스팅 도구를 실행하지 않습니다. 요청·응답·지연 시간·검토 근거는 예시 데이터이며 실제 취약점 발견 결과가 아닙니다. 저장소의 다른 모듈과 실행 경로를 연결하지 않습니다.

실행 이력과 설정은 이 브라우저의 `localStorage`에 저장됩니다. 브라우저를 다시 열면 진행 중이던 실행을 일시정지로 복원합니다. 서버를 종료해도 이력은 남습니다. 실행 상태의 관측 연동은 아직 구현하지 않았습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `dist/index.html` | 대시보드 구조와 접근성 |
| `dist/styles.css` | 레이아웃과 반응형 디자인 |
| `dist/app.js` | 화면 상태, 제어, 이력·검색·내보내기 |
| `dist/engine.js` | 네트워크 호출 없는 모의 이벤트 엔진 |
| `dist/starfield.js` | DESIGN.md에서 영감을 받은 Canvas 별빛 배경 |
| `server.mjs` | 로컬 정적 파일 서버 |

## 검증

```powershell
npm run check
npm test
```

URL 검증, 요청·응답 상관관계, 단계 예산, 일시정지·중지 후 불변성, 기록 직렬화를 테스트합니다.

브라우저에서 데스크톱·모바일 레이아웃, URL 오류 표시, 일시정지, 반복 완료, Agent I/O, 이력 복귀, JSON 복사를 확인했습니다. JSON 내보내기 호출은 확인했지만 앱 내 브라우저에서 다운로드 완료 이벤트를 받지 못해 파일 저장 완료는 확인하지 못했습니다. Chrome 또는 Edge에서 최종 다운로드를 확인하세요.

## 추가 제안

1. 승인된 대상·경로와 실행 시간·단계 예산을 실행 기록에 포함하는 범위 관리.
2. 실제 관측 로그 연결 시 토큰·쿠키·개인정보 마스킹과 열람 권한 분리.
3. 읽기 전용 SSE 스트림으로 기존 실행의 이벤트·상태를 관측하는 어댑터.
4. 모듈 오류·시간 초과 표시와 실행 간 결과 비교.

외부 업로드와 배포를 진행하지 않은 로컬 결과입니다.
