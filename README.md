# 개요
Future Security Lab 지원사업으로 진행하는 CA3P 프로젝트에 대한
국립창원대학교 CASPER의 자료 공유 repository 입니다.

# PR 규칙
## 브랜치
각 모듈마다 브랜치를 새로 설정합니다.
브랜치명은 `닉네임/디렉토리이름(혹은 모듈명)`으로 통일합니다.
## 수정
다른 사람의 작업을 마음대로 수정하지 않기로 합니다.
우선 수정해도 되는지, 어떤 범위를 수정할 것인지 모듈 담당자와 얘기 후 진행합니다.

# 로컬 develop 구성

로컬에 저장된 모듈 브랜치의 기존 개발 사항과 현재 작업 내용을 `develop`에 정리했습니다. 각 모듈의 실행 경계는 유지합니다.

| 디렉터리 | 구성 |
| --- | --- |
| `agent/` | 에이전트 코어와 선택형 Reasoning Provider의 기존 개발 사항 |
| `guardrail/` | 정책 평가기 |
| `pentest-db/` | 검토 데이터와 기록 구조 |
| `xss-parser/` | 기존 요청 분석 모듈 |
| `vul-web-1/` | 기존 실험용 웹 fixture |
| `agent-dashboard/` | 독립 로컬 텔레메트리 시뮬레이션 UI |

대시보드 실행 방법은 [agent-dashboard/README.md](./agent-dashboard/README.md)에 있습니다. 입력 URL에 접속하거나 다른 모듈을 실행하는 연결은 포함하지 않습니다.

`xss-fuzzer/`는 통합 대상에서 제외합니다. 기존 로컬 파일은 유지하되 Git 추적 대상에서 제외하며, 이 제외 이전의 커밋 이력은 보존합니다. `.env`와 생성된 미리보기·호스팅 설정은 개발 커밋에 포함하지 않습니다.
