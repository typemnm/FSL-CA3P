# 전월 CERT 취약점 보고서 작성 양식

상태: 작성 전. 아래는 양식이며 재현 결과가 아니다.

- 보고 날짜: 전월 점검일
- 사례 번호: CASE-001
- 대상 식별자와 발생 URL: 팀의 모의 사이트 정보
- 취약점 종류와 심각도: 팀이 평가한 값
- 자세한 발생 방법: 입력 위치, 사전 조건, 재현 순서, 시험 입력
- 지난달 확인한 증거: 캡처 또는 로그 위치, 관찰한 현상
- 조치 방안: 원인에 대한 수정 권고
- 보고서 작성 당시 패치 상태: 확인한 값 또는 unknown

이 보고서를 작성한 뒤 `case.example.json`을 복사해 내용을 맞춘다.
`ready`는 팀의 전월 보고서를 DB 조회에 제공할 준비가 되었다는 표시다.
이번 달에도 같은 취약점이 존재한다는 판단은 이번 달 재점검 결과로 별도 확인한다.
